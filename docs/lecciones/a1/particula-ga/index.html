Iteración 1: が para señalar el sujeto

Misión: Aprender a usar が para especificar quién o qué realiza la acción.

📐 La partícula が

が marca el sujeto gramatical de la oración. Se usa cuando la información es nueva o cuando se responde a una pregunta de identificación.

  • だれが来ますか — ¿Quién viene?
  • 田中さんが来ます — Viene Tanaka

💬 Ejemplos

  • だれが先生ですか — ¿Quién es el profesor?
  • 私が先生です — Yo soy el profesor
  • 何がおいしいですか — ¿Qué está rico?
  • ラーメンがおいしいです — El ramen está rico

⚠️ Atención

が responde a preguntas de «quién» o «qué». El foco está en el elemento que va antes de が, no en la acción.

Iteración 2: が vs は

Misión: Distinguir cuándo usar は y cuándo usar が.

📐 Contraste は vs が

  • は marca el tema de la oración (información conocida o general)
  • が marca el sujeto específico (información nueva o restrictiva)

は — el elefante tiene trompa larga (hablamos del elefante en general)

ゾウは鼻が長いです

が — el elefante de este zoo tiene la trompa larga (específico)

この動物園のゾウが鼻が長いです

💬 Ejemplos

  • 日本は食べ物がおいしいです — (Hablando de Japón) La comida es rica
  • 京都がきれいです — Kioto es bonito (respondiendo a «¿qué ciudad es bonita?»)

🗣️ Conversación

A: だれが鈴木さんですか

B: あの人が鈴木さんです

A: どの人が田中さんですか

B: 田中さんはあの人です

Iteración 3: Resumen y glosario

Misión: Consolidar el uso de が para especificación.

📌 Resumen

  • が marca el sujeto específico de la oración
  • Responde a preguntas con だれが o 何が
  • は presenta el tema; が especifica el sujeto
  • En estructuras descriptivas, が señala la característica: XはYがZ
