Iteración 1: Posesión y relación entre sustantivos

Misión: Aprender a expresar posesión y relación entre dos sustantivos con の.

📐 La partícula の (posesión)

の une dos sustantivos. El primero modifica o posee al segundo.

`

A の B

`

B de A / el B de A / A's B

💬 Ejemplos de posesión

JaponésTraducciónAnálisis
私わたしの本ほんmi librolibro de mí
田中たなかさんの車くるまel coche del Sr. Tanakacoche de Tanaka
先生せんせいの犬いぬel perro del profesorperro de profesor

📐 の más allá de la posesión

の no solo indica posesión. También expresa relación, pertenencia, origen, ubicación, tipo, materia, etc.

💬 Ejemplos de relación

JaponésTraducciónTipo de relación
日本語にほんごの本ほんun libro de japonéstema / contenido
大学だいがくの先生せんせいprofesor de universidadafiliación
東京とうきょうの駅えきla estación de Tokioubicación
木きの椅子いすsilla de maderamaterial

📐 の con です

Para decir "es de X", se usa の seguido de です.

`

これは私わたしの本ほんです

`

Este es mi libro.

💬 Preguntas con の

`

これは誰だれの本ほんですか

`

¿De quién es este libro?

⚠️ Atención

  • の funciona como la preposición de del español, pero va entre los dos sustantivos
  • En español el orden se invierte a veces ("el libro de Juan"), en japonés siempre es AのB
  • No hay género ni número: 私わたしの本ほん puede ser "mi libro" o "mis libros"
  • Para decir "mío / tuyo / suyo" no se usa の solo; la estructura es 私わたしのです, etc.

🔗 Encadenamiento

Se pueden encadenar varios の:

`

私わたしの友達ともだちの車くるま

`

El coche de mi amigo.

Iteración 2: Resumen y glosario

Misión: Repasar el uso de の y consolidar el vocabulario.

📌 Resumen

  • A の B — B de A / A's B
  • の expresa posesión, relación, origen, tema, material, ubicación
  • El orden es siempre modificador antes de modificado (A の B)
  • Se pueden encadenar varios の (A の B の C)
  • Para preguntar por el poseedor: 誰だれの〜？
  • の no varía con género ni número

📖 Glosario de la lección
