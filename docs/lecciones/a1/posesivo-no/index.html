<section id="iteracion-1" class="slide active"> <h2 class="slide-title">Iteración 1: Posesión y relación entre sustantivos</h2> <p class="mission"><em>Misión: Aprender a expresar posesión y relación entre dos sustantivos con の.</em></p> <h3 class="section-title">📐 La partícula の (posesión)</h3> <p class="body-text"><strong>の</strong> une dos sustantivos. El primero <strong>modifica</strong> o <strong>posee</strong> al segundo.</p> <p class="body-text"><code>`</code></p> <p class="body-text">A の B</p> <p class="body-text"><code>`</code></p> <blockquote>B de A / el B de A / A's B</blockquote> <h3 class="section-title">💬 Ejemplos de posesión</h3> <table><thead><tr><th>Japonés</th><th>Traducción</th><th>Análisis</th></tr></thead><tbody><tr><td><ruby>私<rt>わたし</rt></ruby><ruby>の本<rt>ほん</rt></ruby></td><td>mi libro</td><td>libro de mí</td></tr><tr><td><ruby>田中<rt>たなか</rt></ruby><ruby>さんの車<rt>くるま</rt></ruby></td><td>el coche del Sr. Tanaka</td><td>coche de Tanaka</td></tr><tr><td><ruby>先生<rt>せんせい</rt></ruby><ruby>の犬<rt>いぬ</rt></ruby></td><td>el perro del profesor</td><td>perro de profesor</td></tr></tbody></table> <h3 class="section-title">📐 の más allá de la posesión</h3> <p class="body-text">の no solo indica posesión. También expresa <strong>relación, pertenencia, origen, ubicación, tipo, materia</strong>, etc.</p> <h3 class="section-title">💬 Ejemplos de relación</h3> <table><thead><tr><th>Japonés</th><th>Traducción</th><th>Tipo de relación</th></tr></thead><tbody><tr><td><ruby>日本語<rt>にほんご</rt></ruby><ruby>の本<rt>ほん</rt></ruby></td><td>un libro de japonés</td><td>tema / contenido</td></tr><tr><td><ruby>大学<rt>だいがく</rt></ruby><ruby>の先生<rt>せんせい</rt></ruby></td><td>profesor de universidad</td><td>afiliación</td></tr><tr><td><ruby>東京<rt>とうきょう</rt></ruby><ruby>の駅<rt>えき</rt></ruby></td><td>la estación de Tokio</td><td>ubicación</td></tr><tr><td><ruby>木<rt>き</rt></ruby><ruby>の椅子<rt>いす</rt></ruby></td><td>silla de madera</td><td>material</td></tr></tbody></table> <h3 class="section-title">📐 の con です</h3> <p class="body-text">Para decir "es de X", se usa の seguido de です.</p> <p class="body-text"><code>`</code></p> <p class="body-text"><ruby>これは私<rt>わたし</rt></ruby><ruby>の本<rt>ほん</rt></ruby>です</p> <p class="body-text"><code>`</code></p> <blockquote>Este es mi libro.</blockquote> <h3 class="section-title">💬 Preguntas con の</h3> <p class="body-text"><code>`</code></p> <p class="body-text"><ruby>これは誰<rt>だれ</rt></ruby><ruby>の本<rt>ほん</rt></ruby>ですか</p> <p class="body-text"><code>`</code></p> <blockquote>¿De quién es este libro?</blockquote> <h3 class="section-title">⚠️ Atención</h3> <ul class="body-list"><li>の funciona como la preposición <strong>de</strong> del español, pero va <strong>entre</strong> los dos sustantivos</li><li>En español el orden se invierte a veces ("el libro de Juan"), en japonés siempre es AのB</li><li>No hay género ni número: <ruby>私<rt>わたし</rt></ruby><ruby>の本<rt>ほん</rt></ruby> puede ser "mi libro" o "mis libros"</li><li>Para decir "mío / tuyo / suyo" no se usa の solo; la estructura es <ruby>私<rt>わたし</rt></ruby>のです, etc.</li></ul> <h3 class="section-title">🔗 Encadenamiento</h3> <p class="body-text">Se pueden encadenar varios の:</p> <p class="body-text"><code>`</code></p> <p class="body-text"><ruby>私<rt>わたし</rt></ruby><ruby>の友達<rt>ともだち</rt></ruby><ruby>の車<rt>くるま</rt></ruby></p> <p class="body-text"><code>`</code></p> <blockquote>El coche de mi amigo.</blockquote> </section> <section id="iteracion-2" class="slide"> <h2 class="slide-title">Iteración 2: Resumen y glosario</h2> <p class="mission"><em>Misión: Repasar el uso de の y consolidar el vocabulario.</em></p> <h3 class="section-title">📌 Resumen</h3> <ul class="body-list"><li><strong>A の B</strong> — B de A / A's B</li><li>の expresa posesión, relación, origen, tema, material, ubicación</li><li>El orden es siempre <strong>modificador antes de modificado</strong> (A の B)</li><li>Se pueden <strong>encadenar</strong> varios の (A の B の C)</li><li>Para preguntar por el poseedor: <ruby>誰<rt>だれ</rt></ruby>の〜？</li><li>の no varía con género ni número</li></ul> <h3 class="section-title">📖 Glosario de la lección</h3> <details> <summary>Ver términos nuevos</summary> <ul> <li><strong>の</strong> — partícula de posesión / modificación entre sustantivos</li> <li><strong><ruby>私<rt>わたし</rt></ruby></strong> — yo</li> <li><strong><ruby>誰<rt>だれ</rt></ruby></strong> — quién / de quién</li> <li><strong><ruby>車<rt>くるま</rt></ruby></strong> — coche</li> <li><strong><ruby>犬<rt>いぬ</rt></ruby></strong> — perro</li> <li><strong><ruby>大学<rt>だいがく</rt></ruby></strong> — universidad</li> <li><strong><ruby>駅<rt>えき</rt></ruby></strong> — estación</li> <li><strong><ruby>木<rt>き</rt></ruby></strong> — árbol / madera</li> <li><strong><ruby>椅子<rt>いす</rt></ruby></strong> — silla</li> <li><strong><ruby>友達<rt>ともだち</rt></ruby></strong> — amigo / amiga</li> </ul> </details> </section>
