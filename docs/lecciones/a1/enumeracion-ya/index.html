<section id="iteracion-1" class="slide active"> <h2 class="slide-title">Iteración 1: や para listas de ejemplo</h2> <p class="mission"><em>Misión: Aprender a enumerar ejemplos representativos con la partícula や, indicando que hay más elementos.</em></p> <h3 class="section-title">📐 La partícula や</h3> <p class="body-text">La partícula や se usa para <strong>enumerar ejemplos representativos</strong> de una lista, dando a entender que <strong>hay más elementos</strong> que no se mencionan. Equivale a «y, entre otros» en español.</p> <ul class="body-list"><li><strong>Sustantivo1 + や + Sustantivo2 + や + Sustantivo3</strong></li><li>La lista nunca es completa — solo se nombran algunos ejemplos</li><li>Similar a decir «como... o...» en español</li></ul> <h3 class="section-title">📐 Estructura</h3> <blockquote><strong>[Ejemplo1] や [Ejemplo2] や [Ejemplo3] (など) [partícula de caso] [verbo]</strong></blockquote> <p class="body-text">Se puede añadir <strong>など</strong> al final para enfatizar que «y otras cosas más».</p> <h3 class="section-title">💬 Ejemplos</h3> <table><thead><tr><th>Japonés</th><th>Traducción</th></tr></thead><tbody><tr><td><ruby>本<rt>ほん</rt></ruby><strong>や</strong>ペンがあります</td><td>Hay libros, bolígrafos, etc.</td></tr><tr><td><ruby>野<rt>や</rt></ruby><ruby>菜<rt>さい</rt></ruby><strong>や</strong><ruby>果<rt>くだ</rt></ruby><ruby>物<rt>もの</rt></ruby><ruby>を買<rt>か</rt></ruby>いました</td><td>Compré verduras, frutas, etc.</td></tr><tr><td><ruby>東<rt>とう</rt></ruby><ruby>京<rt>きょう</rt></ruby><strong>や</strong><ruby>大<rt>おお</rt></ruby><ruby>阪<rt>さか</rt></ruby><ruby>に行<rt>い</rt></ruby>きました</td><td>Fui a Tokio, Osaka, entre otros</td></tr><tr><td><ruby>日<rt>に</rt></ruby><ruby>本<rt>ほん</rt></ruby><ruby>語<rt>ご</rt></ruby><strong>や</strong><ruby>英<rt>えい</rt></ruby><ruby>語<rt>ご</rt></ruby><ruby>を勉<rt>べん</rt></ruby><ruby>強<rt>きょう</rt></ruby>しています</td><td>Estudio japonés, inglés, etc.</td></tr></tbody></table> <h3 class="section-title">💡 Contraste con と</h3> <table><thead><tr><th>Partícula</th><th>Significado</th><th>¿Lista completa?</th></tr></thead><tbody><tr><td>と</td><td>enumeración exhaustiva</td><td>Sí</td></tr><tr><td>や</td><td>enumeración no exhaustiva</td><td>No (solo ejemplos)</td></tr></tbody></table> <h3 class="section-title">📝 Práctica</h3> <p class="body-text">Traduce al japonés:</p> <p class="body-text">1.
