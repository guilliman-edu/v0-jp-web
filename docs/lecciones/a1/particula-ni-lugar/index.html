Iteración 1: に de existencia — "está en" / "hay en"

Misión: Expresar dónde existe algo o alguien con ある y いる.

📐 に con ある / いる

La partícula に marca el lugar donde algo existe. Se usa con:

  • ある — para cosas inanimadas (objetos, plantas, fenómenos)
  • いる — para seres animados (personas, animales)

`

[lugar] に [cosa] が ある / いる

`

💬 Ejemplos con ある (cosas)

JaponésTraducción
公園こうえんに猫ねこがいますEn el parque hay un gato
机つくえに本ほんがありますEn la mesa hay un libro
東京とうきょうに博物館はくぶつかんがありますEn Tokio hay un museo
部屋へやに椅子いすがありますEn la habitación hay una silla
ここに電話でんわがありますAquí hay un teléfono

💬 Ejemplos con いる (personas / animales)

JaponésTraducción
学校がっこうに先生せんせいがいますEn la escuela hay un profesor
家いえに犬いぬがいますEn casa hay un perro
教室きょうしつに学生がくせいがいますEn el aula hay estudiantes
公園こうえんに子供こどもがいますEn el parque hay niños

⚠️ に vs で (repaso)

  • に: lugar de existencia — lo que está ahí (con ある/いる)
  • で: lugar de acción activa — lo que haces ahí
公園に猫がいます (el gato existe / está en el parque)
公園で走ります (yo realizo una acción en el parque)

🗣️ Conversación

A: あなたの国くにに有名ゆうめいな建物たてものがありますか

B: はい、東京とうきょうに東京とうきょうタワーがあります

A: 家いえに猫ねこがいますか

B: はい、猫ねこが二匹にひきいます

Iteración 2: Resumen y glosario

Misión: Repasar に de existencia y diferenciarlo de で.

📌 Resumen

  • に marca el lugar donde algo existe (con ある/いる)
  • ある para cosas inanimadas | いる para seres animados
  • El orden es: [lugar] に [sujeto] が ある / いる
  • ある/いる no son verbos de acción, sino de existencia

🆚 に vs で

PartículaVerbo típicoSignificado
にある / いるlugar de existencia
で食べる, 勉強する, 走るlugar de acción
