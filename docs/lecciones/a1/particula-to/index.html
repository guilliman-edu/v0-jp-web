<section id="iteracion-1" class="slide active"> <h2 class="slide-title">Iteración 1: と de compañía — "con alguien"</h2> <p class="mission"><em>Misión: Aprender a expresar con quién se realiza una acción.</em></p> <h3 class="section-title">📐 と de compañía</h3> <p class="body-text">La partícula <strong>と</strong> indica la <strong>persona</strong> con quien se hace algo. Se traduce como <strong>"con"</strong>.</p> <p class="body-text"><code>`</code></p> <p class="body-text">[persona] と [acción]</p> <p class="body-text"><code>`</code></p> <h3 class="section-title">💬
