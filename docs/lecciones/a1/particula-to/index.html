Iteración 1: と de compañía — "con alguien"

Misión: Aprender a expresar con quién se realiza una acción.

📐 と de compañía

La partícula と indica la persona con quien se hace algo. Se traduce como "con".

`

[persona] と [acción]

`

💬 Ejemplos

JaponésTraducción
友達ともだちと映画えいがを見みますVeo una película con un amigo
家族かぞくと食たべますComo con la familia
先生せんせいと話はなしますHablo con el profesor
彼女かのじょと公園こうえんへ行いきますVoy al parque con mi novia
同僚どうりょうと仕事しごとをしますTrabajo con un colega
一人ひとりで勉強べんきょうしますEstudio solo (一人で = sin compañía)

⚠️ Atención importante

  • ✅ 友達と = con un amigo
  • ❌ 友達とは = ✗ (と y は no se combinan así; si contrastas, usas とは pero eso es nivel posterior)
  • 一人ひとりで = "solo, por mi cuenta" (no lleva と)

🗣️ Conversación

A: 週末しゅうまつ誰だれと映画えいがを見みますか

B: 友達ともだちと見みます

A: 毎日まいにち誰だれと食たべますか

B: 家族かぞくと食たべます

Iteración 2: Resumen y glosario

Misión: Repasar と de compañía y fijar el vocabulario.

📌 Resumen

  • と marca la persona que acompaña en la acción
  • Se traduce como "con"
  • Va detrás de la persona y antes del verbo
  • 一人ひとりで se usa para "solo / sin compañía"

🆚 と vs で

PartículaUsoEjemplo
とcompañía — con quién友達と行く
でmedio — con quéバスで行く

📖 Glosario de la lección

  • 家族かぞく — familia
  • 先生せんせい — profesor / profesora
  • 彼女かのじょ — ella / novia
  • 同僚どうりょう — colega de trabajo
  • 一人ひとり — una persona / solo
