Iteración 1: Decir el nombre

Misión: Aprender a decir tu nombre usando わたしは〜です.

📐 Estructura básica

Para presentarte usas:

`

わたしは [nombre] です。

`

Yo soy [nombre].

わたし significa "yo". は marca el tema (se pronuncia wa). です es "ser/estar".

💬 Ejemplos

JaponésTraducción
わたしは田中たなかです。Yo soy Tanaka.
わたしは佐藤さとうです。Yo soy Satō.
わたしはJuanです。Yo soy Juan.

🎌 Fórmula completa de presentación

`

はじめまして。わたしは [名前なまえ] です。

よろしくお願ねがいします。

`

Encantado/a. Soy [nombre]. Mucho gusto.
PalabraSignificado
はじめましてEncantado/a (primera vez)
名前なまえnombre
よろしくお願ねがいしますMucho gusto / Cuento contigo

✍️ Práctica

Escribe tu propia presentación:

`

はじめまして。わたしは ______ です。

よろしくお願ねがいします。

`

Iteración 2: Preguntar y responder el nombre

Misión: Preguntar el nombre a otra persona y responder.

📐 Preguntar el nombre

Para preguntar cortésmente el nombre:

`

お名前なまえは？

`

¿(Su) nombre?

Literalmente: お (prefijo cortés) + 名前なまえ (nombre) + は (partícula de tema) — "¿En cuanto al nombre?"

También puedes decir:

`

お名前なまえはなんですか。

`

¿Cuál es su nombre?

💬 Diálogo completo

PersonaJaponésTraducción
Aはじめまして。わたしは田中たなかです。Encantado. Soy Tanaka.
Bはじめまして。わたしは佐藤さとうです。Encantado. Soy Satō.
Aよろしくお願ねがいします。Mucho gusto.
Bよろしくお願ねがいします。Mucho gusto.

💬 Preguntar y responder

JaponésTraducción
お名前なまえは？¿Su nombre?
わたしは山田やまだです。Yo soy Yamada.
お名前なまえはなんですか。¿Cómo se llama?
山田やまだです。Soy Yamada.

⚠️ Atención

  • お名前なまえ lleva el prefijo cortés お — nunca se dice 名前は？sin el お
  • Se puede responder sin わたしは: basta con 山田やまだです
  • は en お名前は se pronuncia wa

✍️ Práctica

Completa el diálogo:

PersonaJaponés

Tú____________________。

Iteración 3: Resumen y glosario

Misión: Repasar y consolidar todo lo aprendido sobre la presentación personal.

🎯 Errores comunes

ErrorCorrecto
Decir "わたしは田中です" como "watashi wa tanaka desu"✅ Pronunciar は como wa
Decir "名前は？" sin お✅ お名前なまえ es la forma cortés
Olvidar です al final✅ La oración termina siempre con です

📖 Glosario

Ver términos nuevos
  • わたし — yo
  • は — partícula de tema (se pronuncia *wa*)
  • です — verbo ser/estar (presente afirmativo)
  • はじめまして — encantado/a (por primera vez)
  • 名前なまえ — nombre
  • お名前なまえ — nombre (forma cortés)
  • よろしくお願ねがいします — mucho gusto / cuento contigo
  • なん — qué / cuál
  • さん — sufijo cortés (Sr./Sra./Sra.)
