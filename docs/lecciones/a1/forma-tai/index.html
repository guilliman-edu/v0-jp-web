<section id="iteracion-1" class="slide active"> <h2 class="slide-title">Iteración 1: Formación y uso de たい</h2> <p class="mission"><em>Misión: Aprender a conjugar verbos en 〜たい para expresar lo que uno quiere hacer.</em></p> <h3 class="section-title">📐 ¿Qué es la forma たい?</h3> <p class="body-text">La forma <strong>〜たい</strong> se añade a la <strong>raíz del verbo</strong> (la forma ます sin ます) para expresar deseos. Significa «querer hacer [verbo]».</p> <ul class="body-list"><li>Se conjuga como un <strong>adjetivo い</strong></li><li>El sujeto suele ser la <strong>primera persona</strong> (yo)</li></ul> <h3
