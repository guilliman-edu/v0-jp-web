<section id="iteracion-1" class="slide active"> <h2 class="slide-title">Iteración 1: と para listas completas</h2> <p class="mission"><em>Misión: Aprender a enumerar todos los elementos de una lista usando la partícula と.</em></p> <h3 class="section-title">📐 La partícula と enumerativa</h3> <p class="body-text">La partícula と se usa para <strong>enumerar todos los elementos</strong> de una lista de forma exhaustiva. Equivale a «y» en español, pero con la diferencia de que implica que <strong>no faltan elementos</strong> en la lista.</p> <ul class="body-list"><li><strong>Sustantivo1 + と + Sustantivo2 + と + Sustantivo3</strong></li><li>La lista puede tener 2 o más elementos</li><li>Se puede omitir el último と antes del verbo, pero es más claro incluirlo</li></ul> <h3 class="section-title">📐 Estructura</h3> <blockquote><strong>[Elemento1] と [Elemento2] と [Elemento3] (と) [partícula de caso] [verbo]</strong></blockquote> <h3 class="section-title">💬 Ejemplos</h3> <table><thead><tr><th>Japonés</th><th>Traducción</th></tr></thead><tbody><tr><td>りんご<strong>と</strong>バナナ<strong>と</strong><ruby>みかんを買<rt>か</rt></ruby>いました</td><td>Compré manzana, plátano y mandarina</td></tr><tr><td><ruby>犬<rt>いぬ</rt></ruby><strong>と</strong><ruby>猫<rt>ねこ</rt></ruby>がいます</td><td>Hay un perro y un gato</td></tr><tr><td><ruby>日<rt>に</rt></ruby><ruby>本<rt>ほん</rt></ruby><strong>と</strong><ruby>中<rt>ちゅう</rt></ruby><ruby>国<rt>ごく</rt></ruby><strong>と</strong><ruby>韓<rt>かん</rt></ruby><ruby>国<rt>こく</rt></ruby><ruby>に行<rt>い</rt></ruby>きました</td><td>Fui a Japón, China y Corea</td></tr><tr><td><ruby>先<rt>せん</rt></ruby><ruby>生<rt>せい</rt></ruby><strong>と</strong><ruby>友<rt>とも</rt></ruby><ruby>達<rt>だち</rt></ruby><ruby>と食<rt>しょく</rt></ruby><ruby>事<rt>じ</rt></ruby>をしました</td><td>Comí con el profesor y mi amigo</td></tr></tbody></table> <h3 class="section-title">💡 Diferencia clave</h3> <ul class="body-list"><li>と → lista <strong>completa</strong> (todos los elementos están nombrados)</li><li>や → lista <strong>incompleta</strong> (solo se mencionan ejemplos, hay más)</li></ul> <h3 class="section-title">📝 Práctica</h3> <p class="body-text">Traduce al japonés:</p> <p class="body-text">1. Compré un libro y un bolígrafo</p> <p class="body-text">2. Mi padre y mi madre están en casa</p> <p class="body-text">3.
