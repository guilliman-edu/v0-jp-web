Iteración 1: Qué expresa y cómo se forma

Misión: Entender que ～を～として designa el papel, la función, el tema o el material de algo, y montar las tres variantes: として, とする y とした.

📐 Qué expresa

La estructura ～を～として toma un elemento (N1) y le asigna un papel (N2): «tomar X como Y», «designar X como Y», «usar X como Y». El verbo principal dice qué se hace con esa designación: 使つかう, 利用りようする, 選えらぶ, 決きめる, 迎むかえる, 作つくる.

この部屋へやをスタジオとして使つかう。
Uso esta habitación como estudio.
山やまを背景はいけいとした写真しゃしんを撮とる。
Hago fotos con la montaña como telón de fondo.

N2 puede ser un rol (リーダー, 先生), una función (スタジオ, 事務所, 会場), un tema (環境問題, 地域の歴史), un material (米, 和紙) o un centro (駅, 公園).

📐 Cómo se forma

ConstrucciónBaseEjemplo
N1 + を + N2 + として + verboこの部屋をスタジオとして + 使うこの部屋へやをスタジオとして使つかう
N1 + を + N2 + とする会議のテーマを「安全」と + する会議かいぎのテーマを「安全あんぜん」とする
N1 + を + N2 + とした + sustantivo山を背景とした + 写真山やまを背景はいけいとした写真しゃしん

La diferencia entre las tres es de función gramatical: として acompaña a un verbo («usar como»); とする cierra la oración o expresa una decisión («fijar/decidir como»); とした modifica a un sustantivo («con X como…»).

⚠️ Tres trampas

  • ～として no es lo mismo que ～を～として: 彼かれは先生せんせいとして働はたらいている describe su propio papel («trabaja como profesor»); 彼かれを先生せんせいとして迎むかえる designa a otra persona («lo recibimos como profesor»). Sin を no hay objeto designado.
  • とする no es にする: テーマを「環境かんきょう」とする es «fijar/definir el tema como “medio ambiente”»; テーマを「環境かんきょう」にする sería «cambiar el tema a “medio ambiente”». Para designar un papel o un tema, se usa とする.
  • とした necesita un sustantivo detrás: 山やまを背景はいけいとした写真しゃしん es correcto; ✗ 山やまを背景はいけいとした撮とる no lo es, porque とした no puede modificar directamente a un verbo. Para el verbo se usa として: 山やまを背景はいけいとして写真しゃしんを撮とる.

🔗 Conexión

～を～として se combina con ～には para hablar de requisitos: この部屋へやをスタジオとして使つかうには、事前じぜんの予約よやくが必要ひつようです («para usar esta habitación como estudio, hace falta reservar por adelantado»). La primera construcción dice para qué se usa; la segunda, qué hace falta para ello.

Iteración 2: Dos usos y 16 ejemplos

Misión: Asignar roles y funciones a personas, espacios y objetos; fijar temas, materiales y centros; y elegir entre として, とする y とした según la sintaxis.

📐 Uso 1 — asignar un rol o una función

Se designa a una persona para un cargo, o se destina un espacio o un objeto a un uso concreto.

田中たなかさんをリーダーとして、チームを作つくった。
Formamos un equipo con Tanaka como líder.
空あいた部屋へやを事務所じむしょとして利用りようする。
Usamos la habitación libre como oficina.

📐 Uso 2 — fijar un tema, un material o un centro

N2 puede ser el tema de un texto o un evento, el material con el que se hace algo, o el punto central de una organización.

地域ちいきの歴史れきしをテーマとして、展示会てんじかいを開ひらく。
Celebramos una exposición con la historia local como tema.
駅えきを中心ちゅうしんとして、店みせが並ならんでいる。
Las tiendas se alinean alrededor de la estación.

A: いいですね。では、この小ちいさい部屋へやは?
B: 準備室じゅんびしつとして使つかってもいいですか。

— ¿Para qué vais a usar esta habitación libre? — Como recinto para los eventos de la zona. — Buena idea. ¿Y esta habitación pequeña? — ¿Podemos usarla como cuarto de preparación? — Sí, adelante.

Iteración 3: Resumen y glosario

Misión: Repasar las tres variantes de ～を～として y no confundirlas con ～として ni con ～にする.

📌 Resumen

  • ～を～として = «tomar/designar X como Y»: se asigna un rol, una función, un tema, un material o un centro.
  • N1 を N2 として + verbo: この部屋をスタジオとして使う.
  • N1 を N2 とする: 会議のテーマを「安全」とする: fijar o decidir.
  • N1 を N2 とした + sustantivo: 山を背景とした写真: «con X como…».
  • ～として sin を describe el papel del propio sujeto: 先生として働く; ～を～として designa a otro: 彼を先生として迎える.
  • とする ≠ にする: とする fija o define; にする cambia.
  • Se combina con ～には (s4) para expresar el requisito de un uso: ～として使うには、…が必要だ.

✍️ Repaso final

  • 1. Di que usas esta habitación como oficina.
  • 2. Fija el tema de la reunión en «la seguridad del barrio».
  • 3. ¿Por qué 彼は先生として迎えた no equivale a «lo recibimos como profesor»?
Ver soluciones
  • 1. この部屋へやを事務所じむしょとして使つかいます。 — N1 を N2 として + verbo.
  • 2. 会議かいぎのテーマを「町まちの安全あんぜん」とします。 — N1 を N2 とする: fijar el tema.
  • 3. Porque 彼は先生として迎えた describe el papel del sujeto («él recibió como profesor»), no la designación de otra persona. Para «lo recibimos como profesor» hace falta 彼を先生として迎えた.

📖 Glosario de la lección

Ver términos nuevos
  • ～を～として — «tomar/designar X como Y»: asigna un rol, una función, un tema o un material.
  • ～を～とする — «fijar/decidir X como Y»: cierra la oración con una designación.
  • ～を～とした — «con X como Y»: modifica a un sustantivo.
  • として — «como, en calidad de»: describe el papel del propio sujeto.
  • 役割やくわり — papel, función que cumple alguien o algo.
  • テーマ — tema, asunto central de un texto o un evento.
  • 材料ざいりょう — material, ingrediente.
  • 背景はいけい — fondo, telón de fondo.
  • 中心ちゅうしん — centro; punto alrededor del cual se organiza algo.
  • 方針ほうしん — línea, orientación, plan de actuación.
